# Use package-owned hybrid workflows

Matty Workflows live in `@yargote/matty`, are invoked through explicit `/matty`
commands, and do not participate in Pi's global Agent Skill catalog. Each
Workflow Definition splits authority without overlap: package-owned Markdown
Workflow Guidance handles clarification, engineering reasoning, unchanged Matt
Skill composition, and human escalation; executable TypeScript policy owns
authorization, gate order, evidence, budgets, effects, invalidation, re-entry,
and terminal outcomes. Matty injects short versioned routing guidance into the
parent prompt without modifying `ask-matt`, setup skills, `AGENTS.md`, or
`CLAUDE.md`, and validates observable workflow evidence rather than attempting
to certify private model adherence to a skill.

Issue Delivery begins as one deep module behind a small delivery, inspection,
and cancellation interface. A generic workflow DSL or host abstraction will be
extracted only after another real workflow or host demonstrates variation.
