# Make daily development the product after Core

Matty will be an opinionated product for dependable day-to-day software
development, not only a runtime and not a general workflow marketplace. Matty
Core v0.1 retains the boundary established by ADR-0022; the first post-Core
milestone is Matty v0.2 Issue Delivery, which owns one exact ready issue through
protected integration, closure, and cleanup. Matty optimizes for inspectable
evidence and explicit human decisions before speed or autonomy, and a Supported
Workflow earns that status only after deterministic scenarios, protected
acceptance runs, and audited real deliveries.

## Considered Options

A runtime-only product was rejected because every user would still need to
design and integrate daily workflows. A general workflow platform was deferred
because catalog governance and third-party composition would distract from
proving a small number of maintained workflows.
